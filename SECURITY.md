# Security policy

Report a vulnerability privately through
[Security → Report a vulnerability](https://github.com/michal-b-bozek/rdp-primary-monitor/security/advisories/new),
not in a public issue.

Only the latest release is supported. This is a side project with no support (see the
[README](README.md)): reports are read, and fixes are made on a best-effort basis with no deadline.
